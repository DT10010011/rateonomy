Setup instructions

Run this file with "python3 test.py <filename>" with your downloaded farmland image file.
The easiest way to do this is to open VSCode and have all of the files in the same folder.
Also, you need to first obtain a Gemini API key from Google AI Studio.
Google offers a free tier of the Gemini API, so you won't be charged for running this code.
However, the number of requests you can send to Gemini is limited on the free tier, and when the limit
is reached you'll have to wait to run this file again.
